# لعبة هروب أمير من السجن

لعبة باركور للهروب من سجن فيه خمسة أقسام، ولكل قسم شرطي مختلف، مع عملات ومتجر يبيع بالروبوكس وبالعملات.

| الملف | نوع السكربت | مكانه في روبلوكس ستوديو |
|---|---|---|
| `PrisonServer.lua` | Script | ServerScriptService |
| `PrisonClient.lua` | LocalScript | StarterPlayer ← StarterPlayerScripts |

أرقام تذاكر الألعاب **Game Pass** توضع في أعلى ملف `PrisonServer.lua` داخل جدول `SHOP` في الحقل `GamePassId`.
